Key UX Principles

Arabic-First
Default locale Arabic, full RTL layout, Arabic labels. English available via toggle.
Section = Card
Each homepage section is one clickable card. No tables, no CRUD lists.
5 Nav Items Max
Homepage, Posts, Settings, Media, Messages. Nothing else.
Preview Button
Every edit shows "Preview on website" before saving. Uses existing Peek integration.
