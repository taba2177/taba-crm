How It Maps to v1 Data

What Client Sees
القسم الرئيسي → section title + description
كل خدمة → title + icon + short text
حفظ → saves everything
معاينة → live preview via Peek
What Happens Underneath
PostCategory → name, description, subtitle
Post → title, icon, content (per service)
save() → updates PostCategory + Posts
preview → FilamentPeek renders section_component

Section Types & Their Edit Forms

Hero
Title, subtitle, BG image, CTA button text + URL
About / Vision
Title, rich text body, optional image
Services / Cards
Section title + list of items (title, icon, text)
Contact
Phone, email, address, map coords, working hours
FAQ
Section title + Q&A pairs (question + answer)
Portfolio
Section title + project cards (image, title, link)
